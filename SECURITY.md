# Security policy

This policy covers bqto Pro and the bqto Mac app.

Report a vulnerability privately, never in a public issue. Use GitHub's
private vulnerability reporting: on the Security tab of this repository,
choose **Report a vulnerability**. If you cannot use GitHub, write to
hello@pilef.co.

Fixes go into the latest release only.

What bqto does with your identity, network and data is in
bqto's [docs/security.md](https://github.com/pilef-co/bqto/blob/main/docs/security.md).
